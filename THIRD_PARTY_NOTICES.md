# Происхождение кода

В LEctern включён и изменён код трёх проектов. Зафиксированные ревизии и каталоги указаны в [реестре](maintenance/provenance/sources.json).

В исходных снимках нет файла LICENSE. Владелец LEctern подтвердил разрешение авторов на перенос и изменение кода при начальной интеграции. Этот файл не назначает исходному коду новую лицензию.

Исторические README внутри каталогов сервисов сохранены как часть исходных снимков. Действующие команды запуска LEctern находятся в корневом README и документации.
