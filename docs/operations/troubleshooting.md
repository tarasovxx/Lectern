# Решение проблем

## Docker недоступен

```sh
docker info
docker context ls
```

Запустите нужный Docker-сервер и проверьте выбранный context. Ошибка соединения с Unix socket возникает до запуска LEctern.

## Порт занят

Измените PORT в .env, например на 8091, затем повторите команду запуска. Интерфейс будет доступен на новом порту. Не меняйте внутренний порт контейнера для этой задачи.

## Получился демонстрационный транскрипт

Проверьте /api/config. Если там demo, выполните make stop и make local либо make gpu. Переменная в .env не переопределяет режим, который явно задаёт команда make demo.

## Модель pyannote не скачивается

Проверьте HF_TOKEN и принятые условия моделей под тем же аккаунтом. Изменив .env, пересоздайте контейнер командой выбранного режима. Не публикуйте полный лог с токеном.

## Не хватает видеопамяти {#gpu-memory}

Оставьте последовательные стадии: PARALLEL_GPU_STAGES=false. Проверьте nvidia-smi на другие процессы. Уменьшение модели Whisper меняет качество и требует нового замера. Самостоятельный переход на облачный сервис не выполняется.

В режиме gpu-materials речевые модели и Ollama конкурируют за видеопамять. Ollama выгружает модель после ответа, но speech сохраняет свои модели. Во время генерации проверьте размещение модели:

```sh
docker compose -f compose.yaml -f compose.gpu.yaml -f compose.ollama.yaml \
  exec ollama ollama ps
```

В столбце PROCESSOR значение 100% GPU означает полную загрузку модели в видеопамять, 100% CPU — в оперативную память. Смешанное значение означает частичную загрузку на GPU. После ответа список может быть пустым из-за OLLAMA_KEEP_ALIVE=0. Подробности — в [FAQ Ollama](https://docs.ollama.com/faq#how-can-i-tell-if-my-model-was-loaded-onto-the-gpu).

Если памяти не хватает, остановите лишние GPU-процессы или выберите меньшую модель через LOCAL_LLM_MODEL и повторите make gpu-materials. Качество другой модели нужно проверить на своих материалах.

## Локальный сервер генерации недоступен

Проверьте LOCAL_LLM_URL, имя установленной модели и доступность сервера из контейнера ml. Адрес localhost внутри контейнера указывает на сам контейнер. Для сервера на хосте по умолчанию используется host.docker.internal.

В режиме gpu-materials адрес задан как http://ollama:11434/v1. Проверьте, что ollama-init завершился без ошибки:

```sh
docker compose -f compose.yaml -f compose.gpu.yaml -f compose.ollama.yaml \
  logs --tail=100 ollama-init ollama ml
```

Первой загрузке модели нужен доступ к интернету. При ошибке загрузки ml не запустится.

Если транскрипт сохранён, повторите генерацию материалов после исправления адреса. Не загружайте тот же файл заново без необходимости.

## Файл отклонён или обработка завершилась ошибкой

Веб ограничивает загрузку 200 МБ. Для большого видео [извлеките аудио](../guides/local.md#long-recordings). Пустой файл не принимается. При полном лимите очереди веб вернёт 429; повторите загрузку позже.

```sh
make logs
```

Сопоставьте ошибку с id задания. Если после перезапуска не осталось ни файла, ни транскрипта, запись потребуется загрузить заново.
