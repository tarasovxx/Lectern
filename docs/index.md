# LEctern

LEctern обрабатывает записи занятий. Преподаватель загружает файл и получает расшифровку с таймкодами, ролями говорящих и показателями участия. Конспекты, тесты и текстовый анализ речи включаются отдельно.

    Запустите интерфейс без моделей и ключей. [Первый запуск](quickstart.md).

- **Обработать запись**

    Подготовьте модели и выберите CPU или NVIDIA GPU. [Локальный режим](guides/local.md).

## Что доступно

| Задача | Как работает |
|---|---|
| Распознать речь | Локальный Whisper или явно выбранный облачный сервис |
| Разделить говорящих | Локальная обработка всей записи через pyannote |
| Определить роли | Автоматическая оценка преподавателя и учеников |
| Посчитать участие | Длительность и доли речи, смены говорящих, вопросы |
| Создать учебные материалы | Отдельный локальный сервер модели или Gemini |
| Вернуться к результату | История в SQLite и гостевая сессия браузера |

!!! note "Статус проекта"
    Это основа MVP. Роли определяются автоматически; их точность на отложенной выборке пока не подтверждена. Пять методических приёмов и рекомендации с проверенными фрагментами ещё требуют разработки и оценки.

Показатели участия описывают распознанную речь. Из доли речи нельзя сделать вывод о качестве преподавания.
