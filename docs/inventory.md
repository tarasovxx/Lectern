# Проверка исходных проектов

Срез исходников: 11 ноября 2026. Ревизии перечислены в sources.json.

| Источник | Проверено до изменений | Используется в LEctern |
|---|---|---|
| AdaptiveEducationWeb | 8 тестов прошли | Интерфейсы, база, очередь, учебные материалы |
| AdaptiveEducationML | 31 тест прошёл, 2 упали с несовместимым SDK Gemini | Генерация и облачный API; закреплены google-genai 1.75.0 и httpx 0.28.1 |
| yadrovichi | 51 тест прошёл | Обработка целой записи, разделение говорящих и локальная аналитика |

В исходном Web файл полностью загружается в RAM; действует лимит 200 МБ. Переключатель local в исходном ML обращается к внешнему Whisper API и не запускает модель. Поэтому локальный путь LEctern использует отдельный сервис speech и обходит нарезку записи вебом.

Числовые показатели считаются по распознанным репликам. Вопросы в исходной аналитике определяются знаком вопроса; из доли речи нельзя вывести качество преподавания. Роли определяются эвристикой, их F1 на отложенной выборке пока не подтверждена.

Контейнер speech использует маршрут /transcribe с очисткой временной записи. Старые маршруты и Gradio-код оставлены для сопоставления с исходником; Gradio не включён в контейнер. Старый /stream сохраняет исходное поведение хранения и не используется вебом LEctern.

У источников нет файла LICENSE. Владелец LEctern подтвердил разрешение на перенос и изменение всех трёх проектов в этой сессии. Новая общая лицензия чужому коду не назначается.
