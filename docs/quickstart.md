# Первый запуск

Демо позволяет проверить интерфейс, загрузку, очередь и историю. Оно возвращает один синтетический транскрипт для любого загруженного файла. Для распознавания своей записи перейдите в [локальный режим](guides/local.md).

## Подготовьте окружение

Нужны Git, Make, Docker с запущенным сервером и Docker Compose v2.30 или новее.

```sh
git clone https://github.com/tarasovxx/Lectern.git
cd Lectern
cp .env.example .env
```

Если репозиторий уже скачан, выполняйте следующие команды из его корня. Файл .env хранит настройки на вашей машине. Не добавляйте в Git ключи и записи занятий.

## Запустите демо

```sh
make demo
```

Откройте [localhost:8090](http://localhost:8090). Загрузите небольшой аудио- или видеофайл. После обработки в истории появятся транскрипт и локальные показатели. В интерфейсе будет указано, что данные синтетические.

В этом режиме ключи Hugging Face, Groq и Gemini не нужны. Речевые модели не скачиваются.

## Проверьте запуск

```sh
docker compose ps
curl http://localhost:8090/api/config
```

В ответе конфигурации ожидаются значения:

```json
{"transcription_backend": "demo", "generate_materials": false}
```

Для просмотра логов выполните `make logs`. Если страница недоступна, начните с [проверки Docker и порта](operations/troubleshooting.md).

## Остановите сервисы

```sh
make stop
```

База и скачанные модели останутся в Docker volumes — отдельных хранилищах Docker. При смене режима сначала остановите текущую сборку, затем запустите нужную команду. Устройство хранения описано в [разделе о данных](operations/data.md).
