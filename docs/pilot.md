# Подготовка пилота

## Первый реальный прогон

Подготовьте одну запись на 60–90 минут, которую разрешено обрабатывать. Укажите формат занятия, язык, предполагаемое число участников и кто из говорящих преподаватель.

Для стенда нужны ОС, модель GPU, объём видеопамяти, драйвер, RAM и доступный диск. Токен Hugging Face внесите в локальный .env. Облачные ключи для локального прогона не нужны.

Зафиксируйте длительность записи, версию моделей, устройство и полное время обработки. Коэффициент реального времени RTF — отношение времени обработки к длительности записи. Целевой порог проекта — не более 0,4 на согласованном GPU; результат LEctern ещё нужно измерить.

## Проверка качества

Соберите записи разных преподавателей и форматов. До настройки алгоритмов выделите отложенную выборку. Записи одного занятия не должны попадать и в настройку, и в итоговую оценку.

Для контрольных фрагментов нужна человеческая разметка:

| Поле | Пример |
|---|---|
| Начало и конец реплики | 12.4–18.9 секунды |
| Говорящий | speaker_02 |
| Роль | teacher / student / unknown |
| Дословный текст | Почему здесь меняется знак? |
| Методический приём | Согласованная с методистом метка |

Начните с ручной расшифровки 5–10 минут в нескольких записях. Размер итоговой выборки и расчёт метрик согласуйте отдельно. Цели проекта: F1 роли преподавателя ≥ 0,85 и macro-F1 приёмов ≥ 0,70 минимум для пяти классов. Эти показатели пока не подтверждены.

## Работа с методистом

Согласуйте минимум пять приёмов и примеры положительной, отрицательной и спорной разметки. Начальные кандидаты: открытый вопрос, проверка понимания, объяснение на примере, развивающая обратная связь, организация обсуждения. Список требует экспертного согласования.

Подготовьте 10–20 примеров ожидаемого отчёта: наблюдение, время подтверждающего фрагмента, приоритет и рекомендация. Добавьте ошибочные и недопустимые выводы. Требование к рекомендациям — каждая должна содержать наблюдение и ссылку на фрагмент.

Для первого просмотра отчётов нужны методист и 2–3 преподавателя. До загрузки реальных занятий определите доступ, сроки хранения и процедуру удаления, включая кеши, логи и резервные копии. Отдельная оценка пользователем каждого вывода пока требует реализации.
