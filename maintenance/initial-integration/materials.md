# Материалы для следующего этапа

## Для первого реального прогона

- Одна запись занятия длиной 60–90 минут, которую разрешено обрабатывать. Подойдёт аудио; для видео важна читаемая звуковая дорожка.
- Формат занятия: лекция, семинар, защита или обсуждение. Кто из говорящих преподаватель, сколько участников ожидается, какой язык используется.
- Параметры стенда: ОС, модель GPU, объём видеопамяти, драйвер, CUDA, RAM и доступный диск. На нём нужно проверить скорость обработки.
- Токен Hugging Face и принятые условия pyannote. Секрет передаётся через локальный .env, в Git его добавлять нельзя.

## Для измерения качества

Нужны несколько записей разных преподавателей и форматов. Разделение на обучающую и отложенную выборки фиксируется до настройки алгоритмов. Один и тот же преподаватель или занятие не должен случайно оказаться по обе стороны оценки.

Для каждого контрольного фрагмента нужны исходная запись и человеческая разметка:

| Поле | Пример |
|---|---|
| Начало и конец реплики, секунды | 12.4–18.9 |
| Идентификатор говорящего | speaker_02 |
| Роль | teacher / student / unknown |
| Дословный текст | Почему здесь меняется знак? |
| Методический приём | Метка из согласованной таксономии |

Для проверки распознавания речи сначала достаточно вручную расшифровать 5–10 минут в нескольких разных записях. Для заявления F1 ≥ 0,85 по роли и macro-F1 ≥ 0,70 по приёмам потребуется отдельная размеченная выборка с достаточным числом примеров каждого класса. Размер выборки и правила расчёта нужно согласовать с методистом.

## Для педагогических выводов

Нужен методист, который согласует минимум пять классов и примеры положительной, отрицательной и спорной разметки. Начальные кандидаты: открытый вопрос, проверка понимания, объяснение на примере, развивающая обратная связь, организация обсуждения. Предложение требует согласования с методистом.

Полезны 10–20 примеров ожидаемого отчёта: наблюдение, начало и конец подтверждающего фрагмента, приоритет и рекомендация. Нужны также примеры ошибочных и недопустимых выводов. Оценка должна описывать наблюдаемое поведение. Намерения преподавателя из записи установить нельзя.

## Для проверки пользы и обращения с данными

- Контакт методиста и 2–3 преподавателей для первых просмотров отчёта.
- Правила доступа к записям, срок хранения и требуемый объём удаления, включая кеши и резервные копии.
- Доступ к остальным решениям Боткэмпа и материалам первой Мастерской.
- Записанное видео демонстрации, упомянутое в описании проекта: в этой сессии файл или ссылка на него не поступили.

Облачные ключи для локального варианта не нужны. Метрики из README исходных проектов не заменяют замеры LEctern на согласованном стенде.
